# MyBiOut! 绿色版说明

> 目标: **解压即用、双击运行、关闭即退**，降低对 Python 环境与终端的依赖。  
> 约束: **HTTP/API 协议与现有网页版保持不变**。

## 架构

```
MyBiOut.exe
├─ 主线程: pywebview (WebView2) 内嵌窗口
└─ 后台线程: Uvicorn + FastAPI (127.0.0.1:端口)
      └─ 既有 pages HTML + /api/* 契约
```

- 开发态: `pip install mybiout` / `MyBiOut!` / `python -m mybiout`
- 绿色态: 解压目录双击 `MyBiOut.exe`
- 协议: 仍以 `tests/test_api_contract.py` 为门禁

## 路径约定

| 函数 | 含义 |
|---|---|
| `取运行根目录()` | 绿色包 = exe 旁; 开发 = `mybiout/` 包目录。配置与 `auth_profile` 写这里 |
| `取资源根目录()` | 冻结 = `_MEIPASS/mybiout`; 开发 = 包目录。HTML/CSS/内置资源 |
| `取工具目录()` | 优先 `运行根/bin`, 否则资源内 `bin` |

## 启动参数

| 参数 | 说明 |
|---|---|
| `--port N` | 本地服务端口, 默认 23333 |
| `--browser` | 使用系统浏览器, 不启内嵌窗口 |
| `--no-animation` | 跳过终端启动动画 |

默认: 有 `pywebview` 时开内嵌窗口; 冻结包与窗口模式会跳过终端动画。

## 构建绿色包

环境: Windows 11 x64, Python 3.14+

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build_green.ps1
```

或分步:

```powershell
pip install -e ".[green]"
pyinstaller --noconfirm --clean packaging/MyBiOut.spec
python scripts/assemble_green.py
```

产出: `dist/MyBiOut-green/`

将 `bin/` 中的 `BBDown.exe`、`ffmpeg` 等随包分发 (注意各自许可证)。

## 运行时依赖

- **WebView2 Runtime**: Win11 通常自带; Win10 若缺窗口, 引导安装 Evergreen Runtime
- **BBDown / ffmpeg**: 放在绿色包 `bin/` 或系统 PATH
- **Playwright 扫码登录**: 可选, 需本机浏览器; 非绿色包核心依赖

## 与 pip 版关系

| | pip / 源码 | 绿色 zip |
|---|---|---|
| 门槛 | 需 Python 3.14 | 解压双击 |
| UI | 内嵌窗口或 `--browser` | 内嵌窗口 |
| API | 相同 | 相同 |
| 配置 | `mybiout/config.ini` | exe 旁 `config.ini` |
