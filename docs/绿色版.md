# MyBiOut! 绿色版说明

> **唯一发行形态**: 解压即用、双击运行、关闭即退.  
> HTTP/API 协议与页面路由保持稳定, 以 `tests/test_api_contract.py` 为门禁.

## 架构

```
MyBiOut.exe
├─ 主线程: pywebview (WebView2) 内嵌窗口
└─ 后台线程: Uvicorn + FastAPI (127.0.0.1:端口)
      └─ 既有 pages HTML + /api/*
```

用户侧只使用绿色包; 源码树仅供开发/打包.

## 路径约定

| 函数 | 含义 |
|---|---|
| `取运行根目录()` | 绿色包 = exe 旁. 配置与 `auth_profile` 写这里 |
| `取资源根目录()` | 冻结 = `_MEIPASS/mybiout`. HTML/CSS/内置资源 |
| `取工具目录()` | 优先 `运行根/bin`, 否则资源内 `bin` |

## 启动参数

| 参数 | 说明 |
|---|---|
| `--port N` | 本地服务端口, 默认 23333 |
| `--browser` | 使用系统浏览器, 不启内嵌窗口 |
| `--no-animation` | 跳过终端启动动画 |

默认开内嵌窗口; 冻结包与窗口模式跳过终端动画.

## 打包发布

仓库根目录双击 **`打包.bat`**:

1. `pip` 安装构建依赖  
2. `PyInstaller` → `dist/MyBiOut/`  
3. `scripts/assemble_green.py` → `dist/MyBiOut-green/`  
4. `scripts/pack_rar.py` → `dist/release/MyBiOut-<版本>.rar`  

需要本机安装 **WinRAR** (提供 `Rar.exe`).

也可分步:

```cmd
python -m pip install -e ".[green]"
python -m PyInstaller --noconfirm --clean packaging\MyBiOut.spec
python scripts\assemble_green.py
python scripts\pack_rar.py
```

## 运行时依赖

- **WebView2 Runtime**: Win11 通常自带  
- **BBDown / ffmpeg**: 放在绿色包 `bin/`  
- **Playwright 扫码登录**: 可选, 非核心依赖
