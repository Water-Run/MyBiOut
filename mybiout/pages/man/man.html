MyBiOut! 是做什么的

MyBiOut! 是一个把 B 站内容带回本地的工具箱：电脑或手机里已经有缓存，就把它合成可播放文件；手里只有链接，就交给 BBDown 下载；只想留标题、UP、专栏或图文动态，就导出成 Markdown 文档。

这页把每个入口的适用场景、推荐顺序、登录态和常见报错放在一起。第一次使用按下面的顺序走；之后遇到问题，先对照模块和任务状态，信息不够再在右侧输入具体情况。

五个入口，先记牢——选错入口，比凌晨四点起来练错动作还白练：

  • LocalOut! — 视频已经在电脑/手机缓存里 → 合成可播文件
  • BBDown! — 手里只有链接 / BV / av → 在线下载
  • MdOut! — 只要标题、UP、简介这些文字档案 → Markdown（含专栏 / 图文动态正文）
  • OhMyConfig — 导出路径、SESSDATA、大模型开关和 Key 都在这
  • Man!（本页）— 使用说明、排错速查和可选问答入口
先问自己：东西在哪？缓存在本地 → LocalOut；只有链接 → BBDown；只要文档 → MdOut。选错入口，再努力也是在正确的错误上空位打铁。

第一次上手（建议顺序）

  1. 进 OhMyConfig，看导出根目录是不是你想要的（默认 C:\MyBiOut!）。各模块会在下面建子文件夹。
  2. 要高画质、收藏夹、更完整 B 站数据：配 SESSDATA。推荐点 扫码登录获取——B 站 App 扫码即得，走官方登录通道，不碰密码、不养风控；也可以手动粘贴 Cookie。
  3. 大模型：默认关闭。想真 AI 再打开「启用大模型」并填 Key / Model / Base；关掉就永远本地助手，牢大亲自下场整活。
  4. 回首页进模块开干。卡住时：看任务状态原文 → 回设置对路径/凭证。一次只改一个设置，才知道哪一刀生效——曼巴式排障，一次一个动作。

LocalOut!：缓存变成视频

前提：片子已经在本机或手机缓存里。没有缓存就去 BBDown，别在这空扫——没有球就别硬投，先去 BBDown 拿球权。

推荐流程：

  1. 选来源：PC 桌面端缓存 / Android（ADB）/ 自定义文件夹。
  2. 添加源 → 等扫描出卡片（没卡片就先别导出，传不了球）。
  3. 勾选分 P → 加入任务 → 导出。
  4. 完成后「打开目录」找成品。打不开：多半 FFmpeg 不在 bin/ 或 m4s 分片不全——凌晨四点你也合成不出来。

常见坑（对号入座）：

  • PC 扫空：设置里 PC 缓存路径是不是 B 站真实目录（客户端一更新就爱搬家，比转会还勤）。
  • 手机扫不到：USB 调试开着、手机点了允许本机调试、页面环境条能看见设备。ADB 在 bin/ 里要有 adb.exe + 配套 dll。
  • 导出失败：FFmpeg 在不在（绿色包 bin/ 或 PATH）；卡片信息全不全；同一源再扫一次，别反复肘同一个按钮。
  • 文件名翻车：命名模板别堆空字段；Windows 路径别太长、别非法字符。
  • 看起来跑完了目录却空：以导出目录里真有文件为准，不是「感觉跑完了」。

BBDown!：按链接下载

这是 BBDown 命令行的可视化壳：你们贴链接，它排队跑。核心能力是 BBDown 的，页面负责参数和队列——就像教练画战术、球员执行。

能贴什么： BV / av / ep / ss、完整视频/番剧链接、b23 短链。

怎么下： 粘贴 → 选画质/编码/分 P/弹幕字幕封面 → 添加任务 → 看队列。可取消、失败可重试、列表可清空。

常见坑：

  • 高画质不行：先配有效 SESSDATA（建议扫码登录获取）；再确认视频本身有没有那档清晰度。
  • 任务红了：链接有效？Cookie 过期？画质/编码是否存在？bin/ 里有没有 BBDown.exe？一个个肘开排查。
  • 只要音频/弹幕/字幕：在下载内容里勾，不必手写命令行。
  • 很慢：先看网络和 B 站，再考虑降画质、少分 P、改天再来——81 分也不是一分钟刷的。

MdOut!：导出信息文档

只产出 Markdown，不下载视频本体。适合归档标题、UP、标签、收藏夹概览，以及专栏正文 / 图文动态（opus）正文。

能贴什么： BV / av / 视频链接、UID / 空间链接、cv 号 / 专栏链接、opus 图文动态链接、b23 短链。链接里带 ?spm_id_from= 等尾巴也认，不用手动截。

流程： 输入链接或编号 → 解析添加 → 预览（富文本 / 原文）→ 导出选中或全部就绪 →「打开导出目录」核对。

常见坑：

  • 收藏夹/详情缺字段：多半要 SESSDATA（扫码登录即可），或接口权限/风控。
  • 类型认错：换完整链接；确认是视频 / 空间 / 收藏夹 / 专栏 / 图文动态之一。
  • 专栏/opus 正文为空：正文在叶子节点组里面，预览能看到富文本就是抽到了；如果一直空检查网络到 B 站 API 通不通。
  • 预览有字磁盘没有：查导出根目录和 MdOut 子目录名。
  • 一次太多：设置里调请求间隔和收藏详情程度，别把自己限流了——手感热也别一口气扔 50 个链接。

OhMyConfig：先改设置再重试

多数问题不用重启服务：保存 → 回模块重新扫/重新下。孩子们改完设置别在旧失败任务上连点——换套战术重新来。

  • 通用：导出根目录、SESSDATA（扫码登录获取 或手填）、大模型启用开关与 Key / Model / Base / 超时
  • LocalOut：输出名、PC 路径、Android 开关、命名、FFmpeg 并发
  • BBDown：画质编码偏好、文件名模板、弹幕字幕封面
  • MdOut：字段开关、收藏详情、请求间隔

Key / Cookie / SESSDATA 写在本机 config.ini（绿色包根目录旁）。别丢网盘同步盘或公用电脑上——明文密码就是明文，隔着屏幕都能被肘。

大模型：启用开关怎么理解

  • 启用 = 关（默认）：右侧「发送」也走本地助手通道（牢大亲自整活），不请求云端，完全离线。
  • 启用 = 开 且 Key、Model、Base 配对：才真调 OpenAI 兼容接口。
  • 调用失败或 Key 空：仍回落本地通道，不中断你们玩。
  • 「直接说」：强制本地通道，不管开关——适合整活，不保证技术正确，纯属牢大训练赛内容。

示例（Deepseek）：Model deepseek-chat，Base https://api.deepseek.com/v1。

右侧助手怎么问才有用

带上：模块名 + 现象 + 你刚点了什么 + 页面原文。例：

LocalOut 扫安卓缓存，提示没有 ADB 设备，手机已开 USB 调试

比只说「不能用」「寄了」强十倍——就像队医要知道你扭的是左脚还是右脚。左手册查流程，右栏聊具体报错。称呼上我们叫孩子们，你们把问题说清楚就行。

启动参数与版本（进阶）

  • MyBiOut!.exe --port 2026：指定端口（默认 23333）。端口被占时换一个号即可；换不动说明有旧实例还在跑。
  • MyBiOut!.exe --browser：不开内嵌窗口，改用系统浏览器打开——WebView2 缺了 / 坏了 / 不想装的首选方案。
  • MyBiOut!.exe --no-animation：跳过启动直升机动效，直接进入（适合重复调试）。
  • 界面底部版本号来自绿色包根目录 version.txt，中文年月轨：如 二六〇七甲 = 2026 年 7 月第 1 包（甲乙丙丁戊己庚辛壬癸子丑，月内最多 12 包）。

排错速查

  • 功能全挂：设置路径 / SESSDATA（扫码登录获取新版）；模块页环境检测（FFmpeg、BBDown、ADB）。
  • 扫码登录不弹码：网络到 passport.bilibili.com 不通就会生成失败；二维码 3 分钟过期，过期点「刷新二维码」。
  • 目录空：任务是否完成、导出根是否改过、子目录名是否默认。
  • 登录相关挂：重扫码或更新 SESSDATA（过期、截断、风控都常见）。
  • 端口起不来 / 窗口闪退：换 --port；或用 --browser；看绿色目录有无 startup_error.log。
  • 助手不像真 AI：看「启用大模型」开没开、Key/Model/Base/超时；关着本来就是本地通道。
  • 任务卡住：取消当前，改设置后重加；看外部命令是否还在跑。
  • 打包失败：多半旧 exe 还在跑或 dist/ 目录被占用；关掉 MyBiOut!.exe 和资源管理器窗口再打包。

环境与依赖（需要时再看）

  • 目标系统：Windows 11 x64 绿色包；工具在程序旁 bin/ 随包分发
  • FFmpeg：LocalOut 导出必需 → bin/ffmpeg.exe
  • BBDown：在线下载必需 → bin/BBDown.exe
  • ADB：扫手机缓存 → bin/adb.exe（及配套 dll）
  • WebView2：内嵌窗口；Win11 一般自带。没有就弹提示，可 --browser
  • 缺工具 / 窗口起不来：启动弹提示即可，程序仍尽量开；对应功能可能不可用
