📖 MyBiOut! 手册

孩子们，先听一句

能打开这页，说明 MyBiOut! 已经在跑了。这里不讲安装，只讲怎么用、点哪里、坏了先看哪。别慌，一步一步来。

五个入口，先记牢，选错会空转很久：

  • LocalOut! — 视频已经在电脑/手机缓存里 → 合成可播文件
  • BBDown! — 手里只有链接 / BV / av → 在线下载
  • MdOut! — 只要标题、UP、简介这些文字档案 → Markdown
  • OhMyConfig — 导出路径、SESSDATA、大模型开关和 Key 都在这
  • Man!（本页）— 左手册、右助手；助手默认本地通道，整活也行
先问自己：东西在哪？缓存在本地 → LocalOut；只有链接 → BBDown；只要文档 → MdOut。选错入口，再努力也像在正确的错误上加班。

第一次上手（建议顺序）

  1. 进 OhMyConfig，看导出根目录是不是你想要的（默认 C:\MyBiOut!）。各模块会在下面建子文件夹。
  2. 要高画质、收藏夹、更完整 B 站数据：配 SESSDATA（手填 Cookie 或扫码登录）。不配也能用一截功能，但高画质常会哭。
  3. 大模型：默认关闭。想真 AI 再打开「启用大模型」并填 Key / Model / Base；关掉就永远本地助手。
  4. 回首页进模块开干。卡住时：看任务状态原文 → 再回设置对路径/凭证。

LocalOut!：缓存变成视频

前提：片子已经在本机或手机缓存里。没有缓存就去 BBDown，别在这硬扫。

推荐流程：

  1. 选来源：PC 桌面端缓存 / Android（ADB）/ 自定义文件夹。
  2. 添加源 → 等扫描出卡片（没卡片就先别导出）。
  3. 勾选分 P → 加入任务 → 导出。
  4. 完成后「打开目录」找成品。打不开：多半 FFmpeg 或 m4s 分片不全。

常见坑（对号入座）：

  • PC 扫空：设置里 PC 缓存路径是不是 B 站真实目录（客户端一更新就爱搬家）。
  • 手机扫不到：USB 调试开着、手机点了允许本机调试、页面环境条能看见设备。
  • 导出失败：FFmpeg 在不在（PATH 或绿色包 bin）；卡片信息全不全；同一源再扫一次。
  • 文件名翻车：命名模板别堆空字段；Windows 路径别太长、别非法字符。
  • 看起来跑完了目录却空：以导出目录里真有文件为准，不是「感觉跑完了」。

BBDown!：按链接下载

这是 BBDown 命令行的可视化壳：你们贴链接，它排队跑。核心能力是 BBDown 的，页面负责参数和队列。

能贴什么： BV / av / ep / ss、完整视频/番剧链接、b23 短链。

怎么下： 粘贴 → 选画质/编码/分 P/弹幕字幕封面 → 添加任务 → 看队列。可取消、失败可重试、列表可清空。

常见坑：

  • 高画质不行：先配有效 SESSDATA；再确认视频本身有没有那档清晰度。
  • 任务红了：链接有效？Cookie 过期？画质/编码是否存在？bin 里有没有 BBDown.exe？
  • 只要音频/弹幕/字幕：在下载内容里勾，不必手写命令行。
  • 很慢：先看网络和 B 站，再考虑降画质、少分 P、改天再来。

MdOut!：导出信息文档

只产出 Markdown，不下载视频本体。适合归档标题、UP、标签、收藏夹概览、专栏元信息。

流程： 输入链接或编号 → 解析添加 → 预览（富文本 / 原文）→ 导出选中或全部就绪 →「打开导出目录」核对。

常见坑：

  • 收藏夹/详情缺字段：多半要 SESSDATA，或接口权限/风控。
  • 类型认错：换完整链接；确认是视频 / 空间 / 收藏夹 / 专栏之一。
  • 预览有字磁盘没有：查导出根目录和 MdOut 子目录名。
  • 一次太多：设置里调请求间隔和收藏详情程度，别把自己限流了。

OhMyConfig：先改设置再重试

多数问题不用重启服务：保存 → 回模块重新扫/重新下。孩子们改完设置别在旧失败任务上连点。

  • 通用：导出根目录、SESSDATA、大模型启用开关与 Key / Model / Base / 超时
  • LocalOut：输出名、PC 路径、Android 开关、命名、FFmpeg 并发
  • BBDown：画质编码偏好、文件名模板、弹幕字幕封面
  • MdOut：字段开关、收藏详情、请求间隔

Key / Cookie / SESSDATA 写在本机 config.ini（绿色包根目录旁）。别丢网盘同步盘或公用电脑长期挂着——明文就是明文。

大模型：启用开关怎么理解

  • 启用 = 关（默认）：右侧「发送」也走本地助手通道（玩梗/高仿分析），不请求云端。
  • 启用 = 开 且 Key、Model、Base 配对：才真调 OpenAI 兼容接口。
  • 调用失败或 Key 空：仍回落本地通道，不中断你们玩。
  • 「直接说」：强制本地通道，不管开关，适合整活，不保证技术正确。

示例（Deepseek）：Model deepseek-chat，Base https://api.deepseek.com/v1。

右侧助手怎么问才有用

带上：模块名 + 现象 + 你刚点了什么 + 页面原文。例：

LocalOut 扫安卓缓存，提示没有 ADB 设备，手机已开 USB 调试

比只说「不能用」「寄了」强十倍。左手册查流程，右栏聊具体报错。称呼上我们叫孩子们，你们把问题说清楚就行。

排错速查

  • 功能全挂：设置路径 / SESSDATA；模块页环境检测（FFmpeg、BBDown、ADB）。
  • 目录空：任务是否完成、导出根是否改过、子目录名是否默认。
  • 登录相关挂：重扫码或更新 SESSDATA（过期、截断、风控都常见）。
  • 助手不像真 AI：看「启用大模型」开没开、Key/Model/Base/超时；关着本来就是本地通道。
  • 任务卡住：取消当前，改设置后重加；看外部命令是否还在跑。
  • 窗口闪一下没了：看绿色目录旁有没有 startup_error.log；可试 MyBiOut!.exe --browser 或装 WebView2。
