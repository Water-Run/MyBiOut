📖 MyBiOut! 手册

概述

MyBiOut!（My-Bilibili-Output，导出我的哔哩哔哩）是一个已经运行在本机网页里的哔哩哔哩内容导出工具集。看到这个页面时，说明服务已经启动，接下来只需要理解每个页面该做什么、遇到异常该先检查哪里。

系统主要包含五个入口：LocalOut! 导出本地缓存，BBDown! 下载在线视频，MdOut! 导出 Markdown，OhMyConfig 管理全局和模块设置，Man! 提供手册与右侧 AI 助手。

所有导出、下载、解析结果都受本机路径、外部命令、B站登录状态和网络响应影响。遇到问题先看页面提示和任务状态，再看设置页。

推荐使用顺序

  1. 先进入 OhMyConfig 检查导出根目录。默认导出根目录为 C:\MyBiOut!，各模块会在其下创建自己的输出目录。
  2. 如果需要高画质下载、收藏夹读取或更完整的 B 站数据，先配置 B站认证 Cookie (SESSDATA)。可以手动填写，也可以用扫码登录获取。
  3. 按目标选择模块：已有缓存用 LocalOut!，想直接下载链接用 BBDown!，想整理视频/用户/专栏信息为文档用 MdOut!。
  4. 如果不确定某个按钮或错误是什么意思，在右侧问 AI 助手；没有配置大模型时，右侧会用内置生成器降级回复。

LocalOut 使用流程

🎞️ LocalOut! — 本地缓存导出

LocalOut 负责把已经存在于本机或 Android 设备里的 B 站缓存解析出来，并合并为可播放文件。它不是在线播放下载器：如果视频没有被缓存到本地，请使用 BBDown。

可用来源：

  • PC 桌面端缓存：读取桌面端缓存目录，解析 videoInfo.json 和分段文件。
  • Android 设备缓存（ADB）：通过 USB 连接设备，扫描应用缓存目录，解析 entry.json。
  • 自定义本地路径：选择任意已经复制到电脑上的缓存目录，适合从手机手动拷贝后的处理。

标准流程：添加源 → 等待扫描 → 选择视频 → 添加到任务 → 导出

常用设置包括输出目录名、PC 缓存路径、Android 扫描开关、文件名模板、FFmpeg 并发数和标题缺失时的降级策略。文件名模板可以组合 BV号、标题、UP主、分P号、时间等字段。

LocalOut 常见情况

  • 扫描不到 PC 缓存：先在设置页确认 PC 缓存路径；如果 B 站客户端更换了缓存位置，使用“浏览”选择真实目录。
  • ADB 设备不出现：确认手机已开启 USB 调试、已在手机上允许当前电脑调试，并且页面环境检测能找到 ADB。
  • 导出失败或文件打不开：通常与 FFmpeg、biliffm4s、缓存文件缺失或音视频分片不完整有关。重新扫描同一源，确认卡片信息完整后再导出。
  • 标题不完整：使用设置页的命名规则和降级策略，避免空标题、非法字符或过长路径导致导出失败。

BBDown 使用流程

📥 BBDown! — 视频下载

BBDown 页面是对 BBDown 命令行工具的可视化封装，适合直接输入链接或编号下载在线视频。核心下载能力来自 BBDown，本页面负责组织参数、排队任务和展示状态。

支持的输入格式：

  • BV、av、ep、ss 等编号。
  • 完整 B 站视频、番剧、合集链接。
  • b23 短链。

先在页面中填入链接，再按需要选择 API 模式、画质、编码、下载内容、分P范围、弹幕、字幕和封面选项。添加后任务会进入队列，当前任务可取消，失败任务可重试，完成或失败列表可清空。

BBDown 常见情况

  • 高画质不可用：通常需要有效的 SESSDATA。进入设置页配置登录凭证后重试。
  • 任务失败：检查链接是否有效、BBDown 是否可用、Cookie 是否过期、所选画质/编码是否存在。
  • 只想要音频、弹幕或字幕：在下载内容和附加选项里选择对应模式，不需要手动改命令行。
  • 下载很慢：先确认网络和 B 站响应，再考虑降低画质、减少分P范围或稍后重试。

MdOut 使用流程

📝 MdOut! — Markdown 导出

MdOut 用于把 B 站内容整理为 Markdown 文档，适合归档视频信息、用户信息、收藏夹概览或专栏元信息。它不会下载视频本体，只导出结构化文本。

支持三种内容：

  • 视频信息：标题、UP主、简介、数据统计、标签、分P列表等。
  • 用户信息：用户资料、关注粉丝、投稿统计、收藏夹列表和可选详情。
  • 专栏文章：文章标题、作者、简介、数据统计和链接信息。

流程是输入链接或编号，点击解析并添加，等待获取完成后在预览区检查内容。预览支持 Rich 和 Raw 两种模式，确认后可以导出选中项或导出全部就绪项。

MdOut 常见情况

  • 收藏夹或详细信息缺失：通常需要有效 SESSDATA，或受 B 站接口权限/风控影响。
  • 解析类型不对：换用完整链接，或确认输入的是视频、用户空间、收藏夹、专栏中的一种。
  • 导出内容太多或太少：在设置页调整封面、标签、统计、收藏夹详情程度和请求间隔。
  • 预览正常但找不到文件：使用页面“打开导出目录”，并检查导出根目录和 MdOut 输出目录名。

⚙ 设置（OhMyConfig）

设置页是所有模块的控制台。大多数问题不需要重启服务，保存设置后回到对应页面重新添加任务或重新扫描即可。

设置分为四组：

  • 通用设置：导出根目录、统一 SESSDATA、大模型 API。
  • LocalOut 设置：输出目录名、Android 扫描开关、PC 缓存路径、文件命名规则、FFmpeg 并发数。
  • BBDown 设置：画质/编码偏好、文件名模板、弹幕/字幕/封面和下载行为。
  • MdOut 设置：导出选项、收藏夹详情程度、请求间隔、输出目录。

敏感信息提醒：API Key、Cookie、SESSDATA 会写入项目目录下的 config.ini。这是本机工具的便利设计，不适合在共享电脑或会被同步上传的目录里保存长期凭证。

大模型配置与响应

大模型配置只影响 Man 页面右侧助手，不影响 LocalOut、BBDown、MdOut 的基础导出能力。字段含义如下：

  • Key：OpenAI 兼容服务的 API Key。为空时不会调用大模型。
  • Model：模型名称，必须是当前 Base URL 对应服务端认识的名称。
  • Base：OpenAI 兼容接口地址。可以填到服务根路径、/v1，也可以直接填到 /chat/completions。
  • 超时：请求等待时间。网络慢、模型慢或上下文较大时可以调长；不想等待太久时调短。

点击右侧“发送”时，系统会先用 pmc 打包项目代码，再把项目功能地图、回答规范、Mamble/Mamba 风格提示和你的问题一起发送给模型。模型调用失败、Key 为空或响应异常时，会自动降级为内置的计算机主题“狗屁不通文章生成器”。

“直接说”会跳过 API，强制使用内置生成器。它适合看风格和玩梗，不适合当作准确技术结论。

Man! 手册页

左侧是静态手册，适合快速查流程；右侧是「What can I say about...」对话助手，适合问“这个错误是什么意思”“我该点哪里”“为什么没有导出”等具体问题。

提问时尽量包含模块、现象、你刚刚点了什么、页面提示了什么。例如：LocalOut 扫描不到安卓缓存，页面说没有 ADB 设备 比 不能用 更容易得到可执行答案。

常见情况

  • 页面能打开但功能不可用：通常是外部工具、登录凭证、路径或网络问题。先去设置页和对应模块的环境检测区域确认。
  • 导出目录为空：确认任务是否完成、导出根目录是否改过、模块输出目录名是否符合预期。
  • 登录态相关功能失败：重新扫码获取或更新 SESSDATA。凭证过期、被风控、复制不完整都会导致请求失败。
  • 模型助手没有真实回答：检查 Key、Model、Base、超时；如果提示降级，说明大模型没有成功返回。
  • 任务卡住：先看是否有正在运行的外部命令或网络请求；可以取消当前任务，调整设置后重新添加。
  • 文件名异常：Windows 路径长度、非法字符、重复标题和空字段都可能影响导出，优先使用更短、更稳定的命名模板。
